# 真机验收清单（P4）

本清单对应方案 §10.3 的真机验证项，用于 `0.1.0-preview.1` 发布前的 P4 硬化。
建议每台设备复制一份记录；发现的问题请用 GitHub issue 模板（Bug report）提交，
并附上本清单中的设备信息和截图。

## 1. 基本弹出与提交

| # | 项目 | 预期 | 结果 |
|---|---|---|---|
| 1.1 | 点按文本字段 | 遮罩 + 面板弹出，字段值进入编辑框，光标在末尾 | |
| 1.2 | 点遮罩 / 右上角 × / Esc | 关闭且**不写回**目标控件 | |
| 1.3 | 点“确定”或 Enter | 校验通过后写回目标控件并关闭 | |
| 1.4 | 校验失败（如空值、超范围） | 面板保持打开，标题行显示错误，不写回 | |
| 1.5 | 连续点不同字段 | 前一个会话丢弃，新字段正常打开 | |
| 1.6 | 窗口失活/恢复 | 失活时关闭并丢弃；恢复后焦点回到原控件 | |

## 验收通过标准

- 第 1–8 节全部通过，或剩余问题均有 issue 编号并记录影响面。
- 至少覆盖：Windows 11 触摸一台、Linux 一台、macOS 一台，以及 1024×600 与
  1280×800 两种分辨率。
- 已知限制（无 IME、单行编辑、关闭即放弃）在 README 与 `docs/profiles.md` 中可查。
